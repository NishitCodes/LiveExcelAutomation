## 4. Recurring Expenditure Verification & Reconciliation Architecture (SOM vs OH-wise)

This recurring task verifies actual expenditure (**Column I**, `AE as on DD.MM.YYYY`) in the **SOM sheet** against the Ministry's official accounting report (`DD.MM.YYYY.xlsx`, sheet `OH-wise` or `Report`).

### 4.1 Unit Conversion Standard
* **SOM Sheet:** Unit is **Crores (Cr)**.
* **OH-wise Sheet:** Unit is **Thousands (Th)**.
$$\text{Amount (Cr)} = \frac{\text{Amount in Thousands}}{10,000}$$
$$\text{Amount in Thousands} = \text{Amount (Cr)} \times 10,000$$

### 4.2 Column Selection in `OH-wise` (CRITICAL)
In `OH-wise`:
* **Col I (`Expenditure VOTED`):** Direct expenditure booked by the Ministry.
* **Col K (`Amount booked by agent`):** Bookings made by agent ministries/departments (Controller 020, 030, etc.).
* **Col M (`Total Expenditure VOTED`):** **MUST BE USED FOR VERIFICATION.**
  * *Reason:* For scheme heads (e.g. PMIS Advertising & Publicity), agent ministries book huge sums (e.g. ₹11.74 Cr). Col I only shows direct bookings (₹52.66 Lakhs), while Col M reflects the actual total expenditure (₹12.27 Cr), matching BigSheet.

### 4.4 Critical Gotchas & Traps Discovered
1. **SFIO Head Code Divergence:**
   - In `OH-wise`, row 190 lists `34750080057` as the section title.
   - However, the detailed object-head line items (rows 191–210) use head prefix **`3475001055702xx`**.
   - Searching or mapping by `34750080057` yields 0 line items. Always map to `3475001055702xx`.
2. **Swachhta Action Plan (SAP) Collision:**
   - Both regular Office Expenses (`...0013`) and SAP Office Expenses (`...9613`) share the object head code `13`.
   - Never index OH-wise items solely by the last 2 digits without checking for `9613` or description containing `SAP`.
   - In SOM: RoC (R163), OL (R201), and RD (R239) have separate rows titled `SAP - OE`.
3. **Negative Recoveries & Overpayments:**
   - Some heads contain negative expenditures (credits/recoveries):
     - Headquarters Wages (R55): `-29.171` th (`-0.0029171` Cr).
     - NCLT Other Revenue Expenditure (R386): `-781.429` th (`-0.0781429` Cr).
   - If SOM enters `0`, SOM will be over-reported relative to OH-wise.
4. **Classification Mismatches:**
   - In OL Revenue (Table 11), SOM Row 195 (`Advertising & Publicity`) contains `0.00413` Cr, while `Minor Works` (Row 196) is `0`.
   - In `OH-wise`, head `27` (`Minor Civil and Elect`) has `41.3` th (`0.00413` Cr), and `Advertising` is `0`. This is an office-level booking misclassification.
5. **Column R Writing Standard:**
   - Discrepancy Column is always **Column R** (`Col 18`).
   - Header: `Discrepancy (vs DD.MM.YYYY)` at rows `[3, 32, 52, 83, 95, 114, 123, 133, 140, 168, 179, 206, 217, 244, 255, 268, 276, 299, 306, 320, 329, 355, 365, 391, 402, 428]`.
   - Format: `Diff: <diff_cr:+.7f> Cr (OH-wise: <th_val:.3f> th = <cr_val:.7f> Cr)`.
   - Font: `Arial 10pt`, Dark Red font (`#C00000` / `RGB(192, 0, 0)`), Left-aligned.
   - Column Width: `56.0`.
